Settings

    Export

    JSON keeps everything (examples, sources, review progress) and can be imported back. CSV has one row per example sentence. The Anki file imports into Anki 2.1.55+ as “Basic” notes.

    Import

    Import a JSON or CSV file exported from WordHarvest. Words you already have are merged: new example sentences are added, nothing is lost.

    Delete all cards

    Removes every saved word and its review history from this browser. Export first if you want a backup.
